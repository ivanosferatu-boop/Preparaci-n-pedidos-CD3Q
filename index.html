Parámetros de Configuración Firebase:

📌 Para resolver el error [code=not-found]: database (default) does not exist:

Si desea utilizar sincronización remota, asegúrese de haber creado la base de datos Firestore en Firebase Console:

  1. Abra la consola: console.firebase.google.com
  2. Navegue a Build (Compilación) → Firestore Database.
  3. Haga clic en "Crear base de datos" (Create database).
  4. Seleccione la ubicación por defecto y elija "Comenzar en modo de prueba" (Test mode).
